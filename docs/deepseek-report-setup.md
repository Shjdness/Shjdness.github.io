## 配置密钥（由用户在Cloudflare操作）

1. 打开Cloudflare控制台，进入现有Worker `rin-server`。
2. 在Settings中的Variables and Secrets添加Secret，名称为 `DEEPSEEK_API_KEY`，值为用户自己生成的DeepSeek API Key。
3. 按控制台完成保存/部署。不要将Key放普通公开配置、前端环境变量、Git仓库、截图、聊天或日志。

不要修改JWT_SECRET或RSS同步Secret。本阶段不要求给网站购买新服务或设置其他收费API。Key存在也不自动启用AI。若服务名或控制台项目不同，按实际部署项目确认，不复制到其他Worker。
