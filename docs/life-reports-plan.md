# Life 日报、周报与邮件提醒实施任务

2026-11-01 用户批准实施，沿用现有稳定性与数据保护约束。当前以隔离分支 feature/life-reports 开发，阶段验收后合入 main，验证 CI 与线上只读状态；未验收阶段不得称为已上线。

## 产品约定

- 保持主布局与顶栏空间，在 Life 首页右侧增加最近复盘入口，独立 `/life/reports` 展示日报/周报与设置。
- 默认 Asia/Shanghai；08:00 日报总结昨日，周一08:00周报总结上周并合并当日日报，时间可设置。网站后台调度独立于 Codex 本机开发任务。
- 统计由代码计算，AI 只解释事实并提出最多三个行动建议；数据不足明确提示，不推断人格或没有记录等于没有行动。
- 每日执行是记忆清单，不作习惯打卡率。未来构想不作逾期任务；成果与任务完成避免重复统计。所有周期为半开区间，周一为周起点。
- 只包含已同步服务端数据；不读取/清理本机队列，不声称完整生活记录或生成不存在的历史快照。
- 私密正文默认不提交 AI；邮件默认摘要、站内链接登录后访问，不携带登录凭证。不自动更改任务。

## 顺序及验收

1. **统计基础**：北京时间日/周区间、按所属人统计、明确指标口径及合成边界测试。不得遍历整个备份/RSS库；后续 SQL 按账号/日期筛选，检查查询计划和读取预算。
2. **站内第一版**：独立 owner-only 报表预览接口和页面、首页右侧入口；空数据/加载/错误/账号切换/窄屏验收。预览不外调、不发送邮件、不伪装持久历史。
3. **设置与历史**：独立新增表、保守迁移/恢复验证、私密 no-store、按账号访问；保存统计快照、模板版本、设置与投递账本。扩展备份白名单并验证恢复；原表数据、API及ID保留。
4. **AI适配器**：确认服务商、密钥与预算后接入；结构化输出校验、最小数据范围、输入输出上限、超时和统计版降级、固定快照防重调用。日记正文另行明确选择，模型无写工具、不执行正文指令。
5. **邮件适配器**：明确收件邮箱、合法可用发信通道/域名，邮箱验证、HTML转义、纯文本版本、站内私密跳转、暂停/退信。模拟提供商集成先行，用户确认真实收件与通道后验收发送。
6. **后台任务**：Cloudflare scheduled 入口/有界任务处理；账号+类型+周期任务防重、原子抢占和租约、固定报告/请求快照、有限重试。未知邮件提交结果先对账，不盲目重发；提供商幂等窗口过期仍不无限重发。回调验签/防重放，区分受理/送达收件服务器/失败，不把它们等同已读。
7. **发布闭环**：相关隔离测试、类型、构建、人工差异审阅、迁移与备份恢复、main CI及只读探测。开关可停报表且不影响其他业务；报告与配置不进入公开静态资源/公开缓存。
