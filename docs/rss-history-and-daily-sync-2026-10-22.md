# RSS 历史补录与每日同步

## 范围

- 每天北京时间 04:17 由 GitHub Actions 主动抓取一次，平台可能延迟。
- 移除 Worker 的额外 cron；WebSub 属于被动通知，继续接收，不额外轮询。
- 支持条件 HTTP 请求。Feed 未变化返回 304 时跳过解析；内容逐字段相同时不更新视频行。
- WebSub 租约剩余超过两天时不重复续租。
- 手动“更新全部”在浏览器中按频道分摊请求，最多两个并发，避免单个 Worker invocation 承载全部频道的查询。

## 频道评估

先更新近期 Feed，然后使用最近 90 天已收录的精确日期记录作为样本。
已知机构（TED、PBS、NOVA、NASA、SpaceX、BBC、DW、National Geographic、Paramount、MoMA）先补两年。
其他频道：90 天已收录不超过 12 条，或最新发布距今超过 90 天，列为低频/长期停更候选，优先补全可访问历史；高频候选先补两年。
没有近期样本时不武断认定为独立低频频道，先补两年。
该分类是可解释的启发式判断，不是身份认证；样本数量不是频道全集发布量。

## 历史获取与精度

仅通过频道的公开 /videos、/streams 目录提取元数据，不下载视频、音频或封面，不读取浏览器登录信息。
目录相对时间记为 estimated，界面显示“约”；没有日期记为 unknown，不归入虚构的年份。
正常 Feed 的精确发布日期优先于历史估算。补录不覆盖已有丰富简介、已读、收藏或已有精确日期。
两年边界预留 45 天误差缓冲，不删除任何已经存在的更早记录。

每批最多 25 条。单目录 20,000 条、单次 30,000 条和整库 350 MiB 是保护阈值，不是自动删除阈值。
触及阈值、目录不可访问、工具失败均必须记录 partial/failed，不能报告全部完成。
重跑会跳过已完成频道；对未完成频道重复导入已有条目不会制造副本。
超出单目录上限的频道需要提高审核后的上限后再运行；不可访问、已删除和私有视频不承诺找回。

## 数据保护与去重

迁移与历史任务先取得 D1 Time Travel 书签。
0025 迁移按 owner + canonical video ID 合并；保留已读/收藏和其时间，重复行归档至 rss_duplicate_archive。
迁移脚本前后比较全部视频身份与阅读状态，在内存中核验，不打印私人内容。
数据库唯一约束与客户端视频 ID 去重共同防止重入。
新版只清理旧版 RSS 缓存，离线待同步队列不清除；常规缓存最多保存每个范围的第一页，不为每个关键词复制缓存。

## 查询与用量

频道、分组、关键词、发布年份、阅读状态可以组合查询整个已入库资料库。
关键词对标题、简介、作者搜索，百分号和下划线按字面匹配。分页防止全部历史一次进入页面。
界面区分 D1 整库 meta.size_after 实测容量、RSS 文字字段 UTF-8 字节、本机整站缓存。
不再把硬编码 500 MB 冒充当前套餐额度。
近 24 小时入库计量来自 D1 rows_read/rows_written，区分历史、Feed 和推送；不包含监控自身与订阅元数据写入，不冒充账户总消耗。
历史入库记录保留每批前后整库大小；界面展示观察到的整库容量区间，不将其他页面并发写入错误归因于 RSS。
报告与频道决策在私有网站查看，公开 Actions 日志只打印来源编号和汇总，不上传关注列表为公开 artifact。
历史客户端使用明确的 ShjdnessRSS/1.0 User-Agent；默认 Python 标识会被边缘层拦截为 403，认证令牌仍必需。
workflow_run 只接受本站 main 的成功部署事件，并读取当前 main 中经过修正的脚本，避免平台延迟投递旧事件时重新执行旧版本。

## 验收

- Vitest：真实 SQLite 入库重复投递、无变化零视频写入、阅读状态、历史精度、UTF-8 计量、真实服务路由及组合查询。
- Python：0025 去重、归档、不同视频及不同账户保留；频道性质与频率分离判断。
- 浏览器模拟账户：历史分页、频道+年份+简介搜索、字面 %、异步旧响应隔离、未知日期与 320/390/960/1536 布局。
- 发布后应核对 Worker/Pages 发布成功，以及 RSS History 每个来源的真实 complete/partial/failed 状态；本地测试不能替代真实补录结果。

## 内页背景

更换为用户提供的原始 JPEG（约 2.34 MB），使用新资源名避免旧 Service Worker 图片缓存。
Blog/Life 背景无 blur；卡片原有玻璃模糊保留，入口 Garden 背景不变。
