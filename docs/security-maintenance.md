# 持续安全维护检查点

本文件是长期任务的项目检查点，避免重复扫描和无变化发布。任务附着当前聊天，每小时检查一次；实际运行依赖本机项目、应用、权限及可用额度。调度不是额度恢复事件订阅，不购买额度或自动使用重置券。

## 工作约束

- 保留页面布局、HTTP API、用户 ID 和未来模块扩展能力；不清理日记、待办、RSS 收藏已读、标签、离线队列或 IndexedDB。
- 一个周期优先处理一个有证据的小范围问题，按风险、可兼容性与恢复成本排序。额度少时轻量核查并保存检查点；未变化时不重复全量构建、部署或旧风险报告。
- 每小时唤醒不代表每小时全量扫描：没有代码或风险变化时，公开健康探测最多每六小时一次，依赖在线审计通常每天一次；发布失败、新公告或相关代码变化时再增加对应验证。存在待办时优先推进待办，而非重复证明旧版本正常。
- 兼容修补自动测试、审阅、提交 main，并核验既有 CI 与线上只读状态。已有未提交工作不得覆盖；高影响改动先在隔离环境准备可审阅方案。
- 生产加密迁移、密钥轮换、权限扩大、域名/会话切换和私密媒体批量迁移要有恢复路径；不绕过工具审批或提取凭据。旧 R2 公开配置对象删除已由用户暂缓，不能重复尝试绕过权限。
- 不在生产生成测试数据、不爆破、不做压力扫描、不发送真实测试通知。不宣称零漏洞。
